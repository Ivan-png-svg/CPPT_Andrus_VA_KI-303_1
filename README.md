## 2. Мета роботи
Набуття практичних навичок розгортання Java-проєкту з використанням системи збирання Maven, створення відтворюваної інфраструктури розробки через Maven Wrapper, автоматизації тестування за допомогою JUnit 5, статичного аналізу коду через SpotBugs, налаштування continuous integration (CI) у GitHub Actions на трьох операційних системах (Ubuntu, Windows, macOS), організації роботи через GitHub Issues та Pull Request, а також реалізації автоматизованої обробки CSV-даних.

## 3. Постановка задачі
Відповідно до Варіанта 1 необхідно розробити консольну програму для обробки даних каталогу книжок.

**Формат CSV-запису:**
`title;author;pages;price`

| Поле | Тип | Призначення |
| :--- | :--- | :--- |
| `title` | String | Назва книжки |
| `author` | String | Автор книжки |
| `pages` | int | Кількість сторінок |
| `price` | double | Ціна книжки в грн |

**Необхідно обчислити 4 підсумкові показники:**
1. Кількість правильних і неправильних записів.
2. Середню кількість сторінок.
3. Найдорожчу книгу.
4. Сумарну вартість каталогу.

Програма повинна коректно реагувати на помилкові записи, не переривати роботу, фіксувати номери некоректних рядків із причиною пропуску та виводити результат у консоль і зберігати у файл в кодуванні UTF-8.

Потік обробки даних:
1. Зчитування аргументів командного рядка (`--help`, `--version`, `--input`, `--output`).
2. Читання вхідного CSV-файлу через `Files.readAllLines()` у кодуванні `StandardCharsets.UTF_8`.
3. Валідація кожного рядка (перевірка кількості полів, наявності текстових полів, числового формату та додатних значень).

5. Формування підсумкового тексту звіту та збереження його у вихідний файл `out/report.txt`.

## 5. Інфраструктура
* **Java 21:** Основна мова розробки.
* **Maven & Maven Wrapper:** Управління залежностями та збиранням проєкту без обов'язкового встановлення системного Maven.
* **JUnit Jupiter 5.10.2:** Фреймворк для автоматизованого тестування.
* **SpotBugs Maven Plugin 4.8.6.6:** Статичний аналіз байт-коду у фазі `verify`.
* **Maven Shade Plugin:** Створення згортаного виконуваного JAR-файлу.
* **GitHub Actions:** CI/CD пайплайн для тестування й збирання на `ubuntu-latest`, `windows-latest` та `macos-latest`.
