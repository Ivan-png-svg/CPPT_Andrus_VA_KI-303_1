# Лабораторна робота №1

## Розгортання Java-проєкту та базова обробка даних

**Варіант:** 1  
**Предметна область:** Каталог книжок  
**Мова програмування:** Java 21  
**Система збірки:** Maven

## Опис програми

Програма читає каталог книжок із CSV-файлу, перевіряє коректність кожного запису, обчислює показники для коректних записів та формує текстовий звіт.

Формат одного запису для варіанта №1:

```text
title;author;pages;price
```

Поля:

- `title` — назва книжки (`String`);
- `author` — автор (`String`);
- `pages` — кількість сторінок (`int`);
- `price` — ціна (`double`).

Роздільник полів — `;`.

## Обчислювані показники

Для коректних записів програма визначає:

1. кількість коректних записів;
2. середню кількість сторінок;
3. найдорожчу книгу;
4. сумарну вартість каталогу.

Некоректні записи не враховуються під час обчислення показників.

## Валідація

Запис вважається коректним, якщо:

- рядок не порожній;
- містить рівно 4 поля;
- назва книжки та автор не порожні;
- `pages` є цілим числом, більшим за 0;
- `price` є числом і не є від'ємною.

Для некоректного запису програма вказує номер рядка та причину помилки.

## Запуск програми

Після компіляції Maven:

```powershell
mvn -B clean test
```

або через Maven Wrapper:

```powershell
.\mvnw.cmd -B clean test
```

Запуск програми:

```powershell
java -cp target/classes ua.lpnu.kzp.Main --input data/input.csv --output out/report.txt
```

## Аргументи командного рядка

Програма підтримує:

```text
--help
--version
--input <файл>
--output <файл>
```

Без явно заданих шляхів використовуються:

```text
data/input.csv
out/report.txt
```

## Результат роботи

Для наведеного `data/input.csv` отримано:

```text
===== ЗВІТ КАТАЛОГУ КНИЖОК =====
Коректних записів: 5
Некоректних записів: 5
Середня кількість сторінок: 344.80
Найдорожча книга: Кобзар (Тарас Шевченко) (450.00 грн)
Сумарна вартість каталогу: 1540.00 грн

Помилки:
 - Рядок 6: порожня назва книжки або автор
 - Рядок 7: неправильний числовий формат
 - Рядок 8: ціна не може бути від'ємною
 - Рядок 9: кількість сторінок повинна бути більшою за 0
 - Рядок 10: неправильна кількість полів
```

Звіт одночасно виводиться в консоль і записується у файл:

```text
out/report.txt
```

Вхідний і вихідний файли обробляються в кодуванні UTF-8.

## Тестування

Для автоматизованого тестування використовується JUnit 5.

Запуск:

```powershell
mvn -B clean test
```

Перевірено 5 тестів:

- обробка коректного каталогу та обчислення показників;
- обробка некоректних записів;
- обробка порожнього файлу;
- обробка порожнього рядка;
- коректна робота з українськими символами.

Результат тестування:

```text
Tests run: 5, Failures: 0, Errors: 0, Skipped: 0
BUILD SUCCESS
```
