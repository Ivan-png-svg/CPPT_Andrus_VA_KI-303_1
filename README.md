# Лабораторна робота №1

## Розгортання Java-проєкту та базова обробка даних
 
**Варіант:** 1  
**Предметна область:** Каталог книжок  
**Мова:** Java 21  
**Система збірки:** Maven  

---

## Опис

Програма призначена для читання, перевірки (валідації) та обробки даних про книжкові видання з CSV-файлу.

Для кожної книжки використовуються такі поля:

```text
title;author;price;quantity;pages
```

де:

- `title` — назва книжки (`String`);
- `author` — автор книжки (`String`);
- `price` — ціна книжки (`double`);
- `quantity` — кількість примірників (`int`);
- `pages` — кількість сторінок (`int`).

---

## Завдання варіанта №1

Програма обчислює чотири основні показники:

1. Кількість валідних та невалідних записів;
2. Загальну вартість усіх доступних книжок ($\sum(\text{price} \times \text{quantity})$);
3. Середню ціну однієї книжки;
4. Максимальну кількість сторінок серед валідних книжок.

---

## Формат вхідних даних

Вхідний файл містить один запис на рядок.

- **Роздільник полів:** `;`
- **Кодування:** `UTF-8`

### Приклад вхідного файлу (`data/input.csv`):

```csv
Кобзар;Тарас Шевченко;350.00;10;720
Тіні забутих предків;Михайло Коцюбинський;220.00;15;192
Місто;Валер'ян Підмогильний;280.00;8;304
Захар Беркут;Іван Франко;190.00;20;256
Енеїда;Іван Котляревський;300.00;12;350
;Невідомий автор;150.00;5;200
Чорна рада;abc;210.00;10;320
Сонячна машина;Володимир Винниченко;-100.00;5;400
Кайдашева сім'я;Нечуй-Левицький;180.00;нуль;160
Україна в вогні;Олександр Довженко;200.00;7
```

Невалідні рядки **не враховуються** у розрахунках метрик. Для кожної помилки програма виводить номер рядка та причину відхилення запису.

## Запуск

### Через Maven Wrapper

На macOS/Linux:

```bash
./mvnw -B clean verify
```

На Windows (PowerShell / CMD):

```cmd
.\mvnw.cmd -B clean verify
```

---

### Запуск виконуваного JAR (Executable JAR)

Після виконання збірки:

```bash
.\mvnw.cmd -B clean package
```

Програму можна запустити з параметрами:

```bash
java -jar target/lab01-1.0.0.jar --input data/input.csv --output out/report.txt
```

---

### Запуск із внутрішнього класу Main

```bash
java -cp target/classes ua.lpnu.kzp.Main --input data/input.csv
```

---

### Довідка та версія

Перегляд довідки:

```bash
java -jar target/lab01-1.0.0.jar --help
```

Перегляд версії:

```bash
java -jar target/lab01-1.0.0.jar --version
```

---

## Параметри командного рядка

| Параметр | Призначення |
|---|---|
| `--help` | показати довідку з використання |
| `--version` | показати поточну версію програми |
| `--input FILE` | вказати шлях до вхідного CSV-файлу |
| `--output FILE` | вказати шлях для збереження файлу звіту |

За замовчуванням вхідні дані зчитуються з `data/input.csv`.

## Тестування

Запуск JUnit 5 тестів здійснюється командою:

```bash
.\mvnw.cmd -B test
```

Тестовий клас `MainTest.java` перевіряє:

- обробку аргументів `--version` та `--help`;
- некоректні параметри `--input` та `--output`;
- зчитування й обробку валідного CSV-файлу;
- виявлення некоректних і некоректно відформатованих записів;
- обробку порожнього файлу та відсутність вхідного файлу.

## GitHub Actions

У репозиторії налаштовано конвеєр автоматичної збірки та тестування (CI) у файл `.github/workflows/ci.yml`.

Збірка виконується на трьох ОС:

- **Ubuntu** (`ubuntu-latest`)
- **Windows** (`windows-latest`)
- **macOS** (`macos-latest`)

Для кожної ОС перевіряються компіляція, виконання юніт-тестів, SpotBugs-аналіз та створюється виконуваний JAR-файл, який завантажується як **GitHub Actions artifact**.
