## 3. Постановка задачі (варіант 1)

Реалізувати модель книжкового запису з назвою, автором, роком видання, кількістю сторінок та жанром. Створити узагальнений репозиторій для додавання, перегляду та пошуку записів. Описати поля CSV власною анотацією; засобами рефлексії сформувати CSV з детермінованим порядком колонок. Забезпечити імпорт, екранування спеціальних символів, UTF-8, власний перевірюваний виняток, тести та перевірку round-trip. Не порушити роботу лабораторних №1–4.

## 5. Узагальнений репозиторій

`Repository<T>` не залежить від типу предметних даних. Метод `add(T)` додає елемент; `all()` повертає незмінний знімок колекції; `find(Predicate<? super T>)` повертає елементи, що задовольняють предикат. Це дозволяє виконувати пошук без дублювання коду для конкретного класу книжок.

## 6. Анотації та рефлексія

Анотація `@CsvColumn` має область застосування `FIELD` і час збереження `RUNTIME`. Експортер через Reflection API знаходить анотовані поля, враховує успадковані поля та впорядковує колонки за алфавітом Java-імен полів. Заголовки беруться зі значень анотацій.

Для `BookRecord` порядок Java-полів: `author`, `genre`, `pages`, `title`, `year`. Отже, заголовок CSV:

```csv
автор,жанр,сторінки,назва,рік
```

## 7. Формат CSV та зворотний імпорт

У ЛР5 застосовано CSV із комою як роздільником, подвійними лапками для складних полів і UTF-8. Коми, лапки та переноси рядків усередині тексту коректно екрануються. `CsvParser` розбирає документ як послідовність записів, а не як незалежні фізичні рядки, тому підтримує багаторядкові значення.

`BookRecordCsv.read(Path)` читає файл, перевіряє заголовок і перетворює рядки на `BookRecord`. Порожній набір даних з коректним заголовком підтримується. Некоректний заголовок, помилкова кількість полів і недопустимі значення призводять до контрольованого винятку.

**Сумісність:** старий `Main` продовжує використовувати формат `title;author;pages;price`, тому CSV ЛР5 не підмінює формат лабораторних №1–4.

## 8. Винятки та обробка помилок

Власний `DataStorageException` є перевірюваним (`checked`). Для помилок читання/запису файлу та вкладених помилок імпорту зберігається першопричина через `cause`. У `BookRecord.fromCsv(...)` після виправлення SpotBugs не перехоплюється `NullPointerException`; некоректні аргументи перевіряються явно.

## 12. Maven, JAR та зворотна сумісність

Версію `pom.xml` змінено з `4.0.0` на `5.0.0`. Збережено Java 21, JUnit, Maven Shade, SpotBugs і точку входу `ua.lpnu.kzp.Main`. Збірка створює `target/lab01-5.0.0.jar`.

```powershell
.\mvnw.cmd clean verify
java '-Dfile.encoding=UTF-8' -jar target\lab01-5.0.0.jar
java -cp target/classes ua.lpnu.kzp.Lab5Demo
```

До зміни версії запуск попереднього `Main` підтвердив: 5 коректних та 5 некоректних записів, середню кількість сторінок `344.80`, найдорожчу книжку «Кобзар» (`450.00 грн`) і загальну вартість `1540.00 грн`. Збірка версії `5.0.0` підтверджена; запуск нового JAR після зміни версії слід зафіксувати окремим скріншотом.
