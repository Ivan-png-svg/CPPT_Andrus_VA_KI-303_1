## 3. Постановка задачі

### Формат запису

Для варіанта 1 використовується формат:
```text
title;author;price;quantity;pages
Поля:

title — назва книжки (String);

author — автор книжки (String);

price — ціна книжки (double);

quantity — кількість примірників (int);

pages — кількість сторінок (int).

Дані читаються з текстового CSV-файлу у кодуванні UTF-8.

Валідація
Програма перевіряє:

порожні рядки;

кількість полів (має бути рівно 5);

порожню назву книжки чи автора;

числовий формат полів price, quantity, pages;

додатність ціни, кількості примірників та кількості сторінок.

Невалідні записи не потрапляють до розрахунку метрик. Для помилкового рядка виводиться його номер та причина помилки.

Чотири показники варіанта 1
Програма обчислює:

кількість валідних та невалідних записів;

загальну вартість усіх доступних книжок (Σ(price × quantity));

середню ціну однієї книжки;

максимальну кількість сторінок серед валідних книжок.

11. Відповіді на контрольні питання
Яке призначення файла pom.xml?

pom.xml описує Maven-проєкт: координати, версію Java, залежності та плагіни для компіляції, тестування та пакування.

Чим відрізняються фази test, verify і package?

test компілює та запускає тести. package створює виконуваний JAR. verify виконує додаткові перевірки (зокрема SpotBugs) після фази package.

Навіщо потрібен Maven Wrapper?

Дозволяє запускати збірку через .\mvnw.cmd чи ./mvnw із чітко зафіксованою версією Maven без необхідності її окремого встановлення на ПК.

Яку роль відіграє метод main?

Є точкою входу в Java-застосунок, з якої починається його виконання.

Чим примітивний тип відрізняється від String?

Примітивні типи (int, double) зберігають безпосередні значення, а String є об'єктним посилальним типом.

Чому середнє потрібно обчислювати в double, навіть якщо сума й кількість мають тип int?

Щоб зберегти дробову частину результату під час ділення.

Що станеться, якщо Integer.parseInt отримати рядок "abc"?

Буде згенеровано виняток NumberFormatException.

Чому не можна мовчки пропускати рядок із помилкою?

Користувач має знати про некоректність даних та причину відхилення запису.

Як String.split(";", -1) обробляє порожнє останнє поле?

Параметр -1 зберігає порожні елементи в кінці масиву, дозволяючи коректно перевірити кількість полів.

Чому для шляхів краще використовувати Path.of, а не "data\input.csv"?

Path.of забезпечує кросплатформенну сумісність роздільників шляхів між Windows, Linux та macOS.

Навіщо явно задавати StandardCharsets.UTF_8?

Щоб некоректне системне кодування не спотворювало українські літери при зчитуванні та записі файлів.

Чим %n відрізняється від \n у форматованому виводі?

%n підставляє специфічний для поточної ОС роздільник нових рядків.

Які дані потрібно перевірити у вашому варіанті?

Наявність 5 полів, непорожні title та author, а також додатні значення для price, quantity та pages.

Які тести виявлять помилку в обчисленні середнього?

Тести з кількома валідними об'єктами з заздалегідь відомою середньою ціною.

Яке призначення статичного аналізатора?

Аналізує вихідний код чи байт-код на наявність багів та баг-паттернів без виконання програми (SpotBugs).

Яку роль виконує GitHub Actions?

Автоматизує процес CI/CD (збірку, тестування та створення артефактів на декількох ОС).

Що має містити GitHub Issue на дефект?

Назву, опис проблеми, кроки для відтворення, очікуваний та фактичний результати.

Що потрібно вказати у розділі звіту про академічну доброчесність?

Використані ШІ-інструменти, ролі, промпти, прийняті рішення та підтвердження власного розуміння коду.

Яку роботу виконує агент DevOps, а яку — агент Валідатор?

DevOps відповідає за Maven, CI/CD та артефакти; Валідатор — за крайові випадки та юніт-тести.

Який рядок програми найскладніше пояснити і чому?

Використання String.split(";", -1), оскільки параметр -1 є ключовим для виявлення відсутніх полів наприкінці CSV-рядка.
